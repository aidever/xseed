隐私说明

xseed 怎么帮你辅种，以及每一方分别能看到什么。

一次辅种是怎么发生的

  1. 登记指纹小助手给每个种子算一个“文件指纹”交给社区节点。指纹只由文件名和大小算出，看不出内容。
  2. 加密询问别人也有同样文件时，经节点发来一条加密消息：“你在 Y 站有这个吗？”
  3. 会员答题你的小助手出一道只有 Y 站会员才答得上的题，答对了才告诉他种子编号。
  4. 自己下载他用自己的账号去 Y 站下载种子，加进下载器做种。你找辅种也是同样的过程。

社区节点

登记和转发，由不同的人提供

  • 入口节点知道你的 IP
  • 登记节点能看到看不懂的指纹
  • 看不到任何消息内容
  • 没有站点名和种子编号
  • 单个节点对不上“IP”和“指纹”

其他用户

手里有同样文件的人

  • 答对会员题后，知道某个匿名用户在该站有这个种子
  • 拿不到你的 IP
  • 不知道你是谁、还在哪些站
  • 不是会员什么都拿不到

PT 站点

和你平时使用一样

  • 看到你下载了种子、开始做种
  • 不会多出任何别的信息

xseed 承诺不做的事

  • 不删除、不移动你的任何文件，不改动原有的种子
  • 不把 Cookie、passkey 发给任何人，只加密保存在本机
  • 不在站长明确不允许的站点上运行
  • 不读取硬盘上的文件内容（除非你手动开启抽查）
