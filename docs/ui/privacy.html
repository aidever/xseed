隐私说明

xseed 怎么帮你辅种，以及每一方能看到什么。

一次辅种是怎么发生的

  1. 小助手给你下载器里的每个种子算一个“文件指纹”，交给社区节点登记。指纹只由文件名和大小算出，看不出是什么内容。
  2. 别人也有同样文件时，他会经节点给你发一条加密消息，问：“你在 Y 站有这个吗？”
  3. 你的小助手先出一道题，只有 Y 站会员能答上来。答对了，才告诉他 Y 站的种子编号。
  4. 他用自己的账号去 Y 站下载种子，加进自己的下载器做种。反过来，你也是这样从别人那里找到辅种的。

社区节点

负责登记和转发，由不同的人提供

  • 入口节点能看到你的 IP
  • 负责登记的节点能看到不透明的指纹
  • 看不到消息内容
  • 没有站点名和种子编号
  • 单个节点对不上“IP”和“指纹”

其他用户

手里有同样文件的人

  • 答对会员题后，知道某个匿名用户在该站有这个种子
  • 拿不到你的 IP
  • 不知道你是谁、在哪些站
  • 不是会员就什么都拿不到

PT 站点

和你平时用的一样

  • 看到你下载了种子、开始做种
  • 不会多出任何别的信息

xseed 不会做的事

  • 不删除、不移动你的任何文件，也不改动你原有的种子
  • 不把 Cookie、passkey 等登录信息发给任何人，它们只加密保存在本机
  • 不在站长明确不允许的站点上运行
  • 不读取你硬盘上的文件内容（除非你手动开启抽查）
