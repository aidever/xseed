# 页面设计稿 v3「星轨」

设计画布（可交互，点右上角 Play 体验）：<https://claude.ai/artifact/EBGRjtnupSwjxn5dW4fqVX>

`canvas/` 下是画布的源文件（`*.dc.html` 为 Claude Design 画板格式，`canvas.json` 为画布索引）。实际界面以 `crates/xseed-agent/web/` 中的实现为准，实现与本稿冲突时以本稿为准修正实现。

v1、v2 静态稿已废弃，可在 git 历史 `b6c635a` 中找到。

## 1. 设计主线

**星轨**：你的 NAS 在中心，各 PT 站像行星环绕。同一份文件在更多站点做种，就是“星轨上点亮更多行星”。这个意象贯穿概览、站点开关、向导三步，并在向导第 3 步与概览中以同一套图形出现，让用户在设置时看到的东西与日常看到的东西一致。

| 图形状态 | 含义 |
|---|---|
| 实心发光的行星 + 流动虚线光束 | 该站参与辅种，今天有新增 |
| 红色描边行星 + 红色断续线 | 该站有问题（登录失效等） |
| 虚线空心行星，无光束 | 未开启或站长不允许 |
| 中心实心圆 | 你的 NAS；向导最后一步中心变为强调色并显示可辅种数 |

## 2. 视觉基础

### 2.1 色彩令牌

默认深色；浅色、跟随系统可选。所有颜色经 CSS 自定义属性给出，组件内不写死颜色。

| 令牌 | 深色 | 浅色 | 用途 |
|---|---|---|---|
| `--bg` | `#08090B` | `#F4F4F0` | 页面底色，叠 22 px 点阵 `--dot` |
| `--panel` | `#111215` | `#FFFFFF` | 卡片 |
| `--panel2` | `#1A1B1F` | `#ECECE7` | 选中导航、分段控件底、次级面 |
| `--line` / `--line2` | `#212328` / `#2E3137` | `#E2E2DC` / `#CFCFC8` | 分隔线 / 控件边框 |
| `--ink` / `--ink2` / `--ink3` | `#EEEFF1` / `#A9ADB6` / `#868B95` | `#0E0F11` / `#4C5058` / `#666A72` | 正文 / 次要 / 辅助说明 |
| `--ok` `--warn` `--err` `--info` | `#62D49B` `#F2B657` `#FF8076` `#8DB4FF` | `#127347` `#8F5300` `#B0261C` `#2153B3` | 状态（只用于文字、点、细线） |
| `--warn-bg` `--err-bg` | `#2B200F` `#311513` | `#FBEFD9` `#FBE5E2` | 需要处理的横幅 |
| `--heat0` | `#1B1D21` | `#E4E4DE` | 热力格、进度条空槽 |
| 强调色 `accent` | `#C8F169` 青柠（可选冰蓝 `#7DE3F4`、橙 `#FFB35C`、紫 `#B8A3FF`） | 同左 | 只用于“正在发生、点亮”的东西：主按钮、光束、行星、当前导航点 |
| `--acc-text` | 不设（用强调色） | `#4A6600` | 强调色用作文字时，浅色模式改用深绿保证对比度 |

强调色上的文字一律用 `#0A0B0D`。状态颜色不做大面积底色，只有“需要处理”横幅用 `--warn-bg` / `--err-bg`。

### 2.2 字体

| 用途 | 字体 |
|---|---|
| 界面文字 | Inter + Noto Sans SC |
| 数字、文件名、指纹、地址、时间 | JetBrains Mono |
| 页面大标题 | Noto Sans SC 700–800，字距 −0.03em，34–40 px；向导标题 36 px，句式化（“先把下载器接进来。”） |

### 2.3 形状与动效

- 卡片圆角 18 px，控件 8–12 px；边框 1 px，不用阴影区分层级（主按钮的强调色投影除外）。
- 动效只有三种：光束流动（`background-position` 循环）、状态点脉冲、开关滑块位移；`prefers-reduced-motion` 时全部关闭。
- 不用渐变铺底、不用左侧色条卡片、不用 emoji。

## 3. 布局

| 区域 | 规则 |
|---|---|
| 日常页面 | 左侧 220 px 导航（Logo、5 项导航、底部下载器与入口节点状态）+ 右侧内容，内容最大宽 1040 px（设置页 860 px） |
| 向导 | 左侧星轨舞台（≥ 380 px，始终深色）+ 右侧表单，表单最大宽 600 px |
| 窄屏 | 两栏用 `flex-wrap` 自然折行：导航折到顶部、导航项两两并排；向导舞台折到表单上方；卡片网格按 `minmax(260–300px, 1fr)` 自适应 |

## 4. 页面

| 页面 | 画板 | 要点 |
|---|---|---|
| 概览 | `Main.dc.html` | 主视觉：大号“+12”+ 星轨图；五步漏斗“发现同款 → 会员题通过 → 下载种子 → 校验一致 → 开始做种”；需要处理横幅；最近辅种；12 周热力格 |
| 站点 | `Sites.dc.html` | 标题“6 个站点，N 个在辅种”；每站一张卡片（行星头像、主机、开关、本机种子数、由 xseed 辅入数、登录来源、站长态度、今日额度）；PT-depiler 同步区（PT-depiler → xseed 流动连线、三项一键复制、加密密钥） |
| 辅种记录 | `Jobs.dc.html` | 分段筛选（全部 / 做种中 / 进行中 / 失败）；每条记录带五点进度轨，失败步骤红点、进行中步骤闪烁；失败原因用 03 §5.3 的文案；“想全部撤回？”虚线区 |
| 设置 | `Settings.dc.html` | 顶部大开关“你正在帮别人找到辅种”（开启时泛光并显示互助统计）；每日上限步进器；下载器、入口节点、抽查、管理员密码按行排列 |
| 隐私说明 | `Privacy.dc.html` | “换个身份，看看别人能看到你什么”：选择入口节点 / 登记节点 / 其他用户 / PT 站点，档案只露出该方可见字段，其余涂黑；四步说明；承诺不做的事 |
| 向导 ② 下载器 | `Setup1.dc.html` | 舞台：NAS 与下载器相连，外圈轨道空着“站点稍后出现在这条轨道上” |
| 向导 ③ 站点 | `Setup2.dc.html` | 勾选站点时舞台上的行星实时点亮 / 熄灭 |
| 向导 ④ 试运行 | `Setup3.dc.html` | 标题“你的硬盘里，藏着 2.1 TB 还能多做种的内容。”；舞台光束按各站数量粗细不同；主按钮“点亮星轨，开始辅种” |

各页的数字均为示意数据。
